# Кто кому

PWA для Android: учёт долгов — кто кому должен, суммы в евро, годовой процент
на остаток с начислением каждый день. Работает офлайн, ставится на главный экран,
данные хранятся только на телефоне.

**Живая версия: <https://derrij.github.io/who2whom/>** — открыть на телефоне и установить.

## Что умеет

- **Долги в две стороны**: «мне должны» и «я должен».
- **Сумма в €** и **ставка, % годовых** — проценты считаются каждый день от остатка,
  зачисляются как в банке: раз в месяц, с капитализацией и округлением до копеек.
- **Оплаты**: частичные, в любой день; сначала гасят начисленные проценты, потом тело долга.
- **Погасить полностью** — долг закрывается, начисление процентов останавливается, запись уходит в «Закрытые».
- **Итоги**: сколько должны мне, сколько должен я, сальдо.
- **Способ расчёта** как в договоре: база 365 / 365–366 / 360 и зачисление процентов
  раз в месяц, раз в год, ежедневно или без капитализации.
- **Эффективная ставка** и **разбивка начислений по месяцам** — чтобы сходиться с выпиской банка.
- **Копия данных** в JSON (экспорт/импорт) и офлайн-работа через service worker.

## Как считается процент

```
проценты за день = остаток × (ставка % / 100) / база дней
```

- **База дней** — 365 (как у банков еврозоны), «365 или 366» (вклад в РФ: в високосном
  году дни делятся на 366) или 360 (как по кредитам и овердрафтам).
- **Начисление** идёт за каждый день использования: со дня, следующего за датой выдачи,
  по день возврата включительно.
- **Зачисление** — момент, когда накопленные проценты прибавляются к телу долга:
  раз в месяц (по умолчанию, как у накопительного счёта), раз в год, каждый день или
  никогда (простые проценты — копятся отдельно).
- При зачислении сумма **округляется до копеек** — как в выписке банка.

Способ один для всех долгов, меняется в Настройках. По умолчанию включён банковский:
база 365, зачисление раз в месяц с капитализацией.

1000 € под 12 % годовых:

| Способ расчёта | Начисление | Результат |
|---|---|---|
| **EUR-банк: раз в месяц (по умолчанию)** | со 2 января по 31 декабря 2026 | **1126,46 €** |
| **EUR-банк: раз в месяц** | за 365 дней | **1126,83 €**, эффективная ставка 12,68 % |
| EUR-банк: раз в год | 2026 год | 119,67 € за год, за два года 1254,03 € |
| Простые проценты, база 365 | 365 дней | 1120,00 € |
| Вклад 365/366 (високосный год) | 365 дней 2028 года | 1119,67 € (365 ÷ 366) |
| Капитализация ежедневно | 365 дней | 1127,47 € |
| База 360 (кредит) | 365 дней | 1121,67 € |

Эти же числа закреплены тестами (`tools/test.cmd`) и сверены с отдельной реализацией
на Python, чтобы расхождение с банком было только из-за условий договора, а не из-за арифметики.

Что ещё важно:

- Оплата сначала гасит начисленные проценты, затем тело долга; остаток уменьшается со дня платежа.
- В карточке долга видно **эффективную ставку** — её можно сравнить со ставкой банка:
  например, 12 % при ежемесячном зачислении дают 12,68 %.
- Есть **разбивка начислений по месяцам** (месяц → начислено → зачислено → остаток), чтобы
  построчно сойтись с выпиской банка.
- В закрытых долгах начисление останавливается на дате закрытия, поэтому сумма
  не «растёт» задним числом.

## Запуск на компьютере

Нужен локальный сервер (с файла `file://` браузер не даёт сохранять данные и не ставит
service worker):

```powershell
# вариант 1 — скрипт
.\serve.cmd

# вариант 2 — вручную
python -m http.server 8080
```

Открыть: http://localhost:8080

## Установка на Android

Service worker и установка PWA работают только в защищённом контексте (https или localhost).
Адрес `http://192.168.x.x` для установки **не** подходит.

1. **Опубликованная версия (просто и всегда доступно).** Откройте на телефоне
   <https://derrij.github.io/who2whom/> в Chrome → меню ⋮ → «Установить приложение».
2. **Проверка локальных правок по USB.** Телефон по USB, на компьютере Chrome →
   `chrome://inspect/#devices` → **Port forwarding** → `8080` → `localhost:8080` → включить,
   затем на телефоне открыть `http://localhost:8080`.
3. **Туннель с https** — например `cloudflared tunnel --url http://localhost:8080`, открыть выданный https-адрес на телефоне.

GitHub Pages уже настроен: ветка `main`, корень репозитория. Публикация происходит
автоматически при пуше, через минуту-другую изменения появляются на сайте.
После установки приложение открывается без браузерной строки и работает офлайн.

## Обновление версии

После правки `app.js` / `styles.css` поднимите номер кэша в `sw.js`
(`const CACHE = 'kto-komu-v2'`) — иначе телефон может отдать старую версию из кэша.

## Файлы

```
index.html              оболочка
styles.css              оформление (тёмная тема, мобильная вёрстка)
app.js                  вся логика: долги, проценты, оплаты, экспорт/импорт
sw.js                   service worker (офлайн-кэш)
manifest.webmanifest    описание PWA (иконки, цвета, standalone)
icons/                  иконки 192/512 + maskable
serve.cmd               локальный сервер на 8080
tools/make-icons.ps1    перегенерация иконок
tools/test.cmd          запуск всех тестов
tools/test-calc.cjs     тесты расчёта процентов
tools/test-ui.cjs       тесты экранов и действий (добавить, оплатить, закрыть)
tools/harness.cjs       заглушки браузера для тестов в Node
tools/ref-calc.py       независимая (Python) реализация расчёта для сверки
```

## Тесты

```powershell
.\tools\test.cmd
```

146 проверок без браузера: арифметика процентов по всем способам расчёта (банковский
с ежемесячным зачислением и округлением до копеек, простые проценты, 365/366, база 360,
ежедневная и годовая капитализация, високосный год, оплаты внутри месяца, переплата),
логика экранов (валидация формы, добавление, правка, оплата, закрытие долга, удаление,
итоги) и настройки способа расчёта.

Независимая сверка (`python tools\ref-calc.py`) считает те же суммы другим кодом —
чтобы ошибка не «спряталась» одинаково в двух местах.

## Данные

Всё лежит в `localStorage` браузера под ключами `kto-komu:data:v1` и `kto-komu:settings:v1`.
Резервная копия — Настройки → «Скачать копию (JSON)». Импорт объединяет записи по `id`.

Удаление приложения с телефона **удаляет долги** — сначала сделайте копию.
