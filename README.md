# Кто кому

PWA для Android: учёт долгов — кто кому должен, суммы в евро, годовой процент
на остаток с начислением каждый день. Работает офлайн, ставится на главный экран,
данные хранятся только на телефоне.

## Что умеет

- **Долги в две стороны**: «мне должны» и «я должен».
- **Сумма в €** и **ставка, % годовых** — проценты считаются каждый день от остатка.
- **Оплаты**: частичные, в любой день; сначала гасят начисленные проценты, потом тело долга.
- **Погасить полностью** — долг закрывается, начисление процентов останавливается, запись уходит в «Закрытые».
- **Итоги**: сколько должны мне, сколько должен я, сальдо.
- **Копия данных** в JSON (экспорт/импорт) и офлайн-работа через service worker.

## Как считается процент

```
проценты за день = остаток × (ставка % / 100) / 365
```

Проценты начисляются за каждый полный день, начиная со дня, следующего за датой выдачи.
Есть два режима (Настройки → Проценты):

| Режим | Что происходит | Пример: 1000 €, 12 % годовых, ровно год |
|---|---|---|
| Капитализация включена (по умолчанию) | проценты прибавляются к остатку, и на них тоже идут проценты | 1127,47 € |
| Капитализация выключена | простые проценты, только на тело долга | 1120,00 € |

В закрытых долгах начисление останавливается на дате закрытия, поэтому сумма
не «растёт» задним числом.

## Запуск на компьютере

Нужен локальный сервер (с файла `file://` браузер не даёт сохранять данные и не ставит
service worker):

```powershell
# вариант 1 — скрипт
.\serve.cmd

# вариант 2 — вручную
python -m http.server 8080
```

Открыть: http://localhost:8080

## Установка на Android

Service worker и установка PWA работают только в защищённом контексте (https или localhost).
По локальной сети через `http://192.168.x.x` установка **не** сработает. Варианты:

1. **USB-порт (быстро и без интернета).** Телефон по USB, на компьютере Chrome →
   `chrome://inspect/#devices` → **Port forwarding** → `8080` → `localhost:8080` → включить.
   Затем на телефоне открыть `http://localhost:8080` и установить приложение.
2. **Туннель с https** — например `cloudflared tunnel --url http://localhost:8080`, открыть выданный https-адрес на телефоне.
3. **Хостинг** — выложить папку на GitHub Pages / Netlify (статикой) и открыть по https.

Установка в Chrome на Android: меню ⋮ → «Установить приложение» (или кнопка в Настройках приложения).
После установки приложение открывается без браузерной строки и работает офлайн.

## Обновление версии

После правки `app.js` / `styles.css` поднимите номер кэша в `sw.js`
(`const CACHE = 'kto-komu-v2'`) — иначе телефон может отдать старую версию из кэша.

## Файлы

```
index.html              оболочка
styles.css              оформление (тёмная тема, мобильная вёрстка)
app.js                  вся логика: долги, проценты, оплаты, экспорт/импорт
sw.js                   service worker (офлайн-кэш)
manifest.webmanifest    описание PWA (иконки, цвета, standalone)
icons/                  иконки 192/512 + maskable
serve.cmd               локальный сервер на 8080
tools/make-icons.ps1    перегенерация иконок
tools/test.cmd          запуск всех тестов
tools/test-calc.cjs     тесты расчёта процентов
tools/test-ui.cjs       тесты экранов и действий (добавить, оплатить, закрыть)
tools/harness.cjs       заглушки браузера для тестов в Node
```

## Тесты

```powershell
.\tools\test.cmd
```

Проверяют арифметику процентов (день, год, капитализация, оплаты, закрытие,
переплата, високосный год) и логику экранов: валидация формы, добавление,
редактирование, оплата, закрытие долга, удаление, итоги. 82 проверки, браузер не нужен.

## Данные

Всё лежит в `localStorage` браузера под ключами `kto-komu:data:v1` и `kto-komu:settings:v1`.
Резервная копия — Настройки → «Скачать копию (JSON)». Импорт объединяет записи по `id`.

Удаление приложения с телефона **удаляет долги** — сначала сделайте копию.
